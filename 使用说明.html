GT Spirit / Veloce

Explore one realtime 3D scene from the cloth reveal through Paint, Engine and Structure. Designed for desktop viewing.

Controls

ChapterExplore
IntroScroll forward or back through the reveal. Use the timeline to seek. Fullscreen includes the whole experience.
PaintScroll to preview colors. Select a swatch for this chapter; select Auto to resume the preview. Paint returns smoothly to the original silver before Engine.
EngineScroll to open the hood, or use Open and Close. Drag horizontally for a limited view adjustment.
StructureScroll to expand or assemble. Select Vertical or Horizontal for the layout, then select a part to see its details.

Scrolling can take over a button transition at any time. Engine and Structure stay silver. Your selected paint returns when you scroll back into Paint; Intro always stays silver.

Run locally

Run the launcher beside this project, or use Node.js 22 or newer:

npm run preview
# Choose another port if needed:
node scripts/server.mjs --root dist --port 4177

Keep the terminal open. Press Control+C to stop. Assets and dependencies are local; the experience does not require a CDN or upload models.

Model notes

The intro is realtime 3D. The source camera animation and precomputed cloth deformation follow frames 30–504 of the original scene. Scrolling selects the animation pose; the browser renders its geometry, materials, lighting and shadows at the current viewport resolution. No PNG sequence or video is played.

All chapters share the same scene and renderer, keeping lighting, reflections and post-processing consistent. Render resolution may decrease on slower hardware to keep interaction responsive. Desktop camera framing fills the stage with centered cropping where the viewport aspect ratio differs.

The live vehicle retains the source exterior, textures and all 968 mechanical reference parts. The CAD body structure uses a satin metal finish. Its internal A-pillar reinforcements appear during disassembly. These parts are for visual exploration, not manufacturing or repair. The original Blender project and original image sequences remain intact as source archives.

Hood motion remains a preview. The source hood's contact with the light covers and window frame is unchanged. The source does not include verified hinge dimensions or a complete inner hood structure. The exploded layouts are viewing arrangements, not tested disassembly paths.

The surrounding garage derives from the same source scene. Browser rendering approximates the Blender reference while using one consistent look throughout the website. Browser axes are X left/right, Y up/down and Z forward.

Development

npm run verify
npm run build
npm run dev

Verification checks source integrity, camera and cloth animation data, presentation geometry, model assets and state invariants. A successful build does not validate the hood geometry. Visual checks prioritize desktop viewports.

The original camera timeline remains in public/scene.json. The original image sequence remains in public/frames/ and the archived text-free sequence in public/clean-frames/. Model provenance is recorded in public/models/vehicle.json and public/models/stage.json.

Local preview. No public deployment.
